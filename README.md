# LifeOS – Personal Digital Command Center

LifeOS is a C++ desktop application developed using Qt 6. It provides a centralized platform for managing personal activities.

## Features

* Dashboard
* Task Manager
* Calendar
* Habit Tracker
* Personal Finance
* Notes
* Analytics
* Settings

## Technologies Used

* C++
* Qt 6
* Qt Widgets
* SQLite
* Qt SQL
* CMake

## Installation

1. Clone or download this repository.
2. Install Qt 6 and CMake.
3. Configure the project using CMake.
4. Build and run the application.
